# Changesets

Each Markdown file here describes one change for the next release. Add one with `npx changeset`
in any pull request that changes what users get: code, types, calendar data or the README's
documented behavior. Write the summary for someone deciding whether to upgrade. It becomes the
change's entry in [CHANGELOG.md](../CHANGELOG.md).

[CONTRIBUTING.md](../CONTRIBUTING.md#changesets) explains which release type to choose, and how
releases are published.
